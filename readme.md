# ♛ Ultimate Chess Arena

A modern chess game built using HTML, CSS, and JavaScript.

## Features

- Player vs Player Mode
- Player vs AI Mode
- Easy / Medium / Hard AI
- Move History
- Chess Timers
- Material Evaluation
- Pawn Promotion
- Castling
- En Passant
- Check & Checkmate Detection
- Responsive Design
- Dark / Light Theme
- ELO Rating System

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
